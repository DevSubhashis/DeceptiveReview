# Uncovering Deceptive Reviews Using Machine Learning and NLP Techniques with Power BI for Strategic Insights

## 📌 Project Overview

Online educational review platforms play a significant role in helping students choose colleges and universities. However, the presence of deceptive or manipulated reviews can mislead students and affect institutional reputation. This project aims to detect deceptive educational reviews using Machine Learning and Natural Language Processing (NLP) techniques and provide strategic insights through data visualization and dashboards.

The project uses engineering college reviews collected from Indian educational institutions and applies NLP preprocessing, sentiment analysis, feature extraction, and classification algorithms to distinguish genuine reviews from deceptive ones.

---

## 🎯 Objectives

* Detect deceptive reviews using Machine Learning models.
* Apply NLP techniques to analyze review text.
* Extract meaningful features from textual data.
* Compare multiple classification algorithms.
* Generate strategic insights using visualizations and dashboards.
* Support educational institutions in identifying suspicious review activity.

---

## 📊 Dataset

**Source:** Kaggle – Indian College Reviews Dataset

The dataset contains reviews collected from engineering colleges in India.

### Dataset Attributes

* College Name
* Review
* Rating

### Dataset Statistics

| Description       | Count     |
| ----------------- | --------- |
| Original Records  | 28,076    |
| Final Records     | 40,003    |
| Genuine Reviews   | Label = 0 |
| Deceptive Reviews | Label = 1 |

Since naturally labeled deceptive reviews were unavailable, realistic fake reviews were generated by modifying genuine reviews and introducing deceptive review characteristics.

## 🔄 Project Workflow

### 1. Data Collection

* Collected engineering college reviews from India.
* Merged multiple datasets into a single dataset.
* Performed initial data inspection.

### 2. Data Preprocessing

* Removed missing values.
* Removed empty reviews.
* Removed unnecessary columns.
* Converted text to lowercase.
* Cleaned special characters and unwanted spaces.
* Generated review labels.

### 3. Exploratory Data Analysis (EDA)

Created visualizations including:

* Label Distribution
* Rating Distribution
* Review Length Distribution
* Word Clouds
* Most Common Words
* Top Colleges with Most Reviews
* Sentiment Analysis

### 4. NLP Feature Extraction

Applied NLP techniques:

* Tokenization
* Stopword Removal
* Lemmatization
* Sentiment Analysis
* TF-IDF Vectorization

### 5. Model Development

Implemented and compared:

* Logistic Regression
* Multinomial Naive Bayes
* Random Forest Classifier

### 6. Dashboard Creation

Created interactive dashboards using Power BI to visualize:

* Review trends
* Sentiment patterns
* Rating behavior
* College-wise review activity
* Deceptive review insights

## 📈 Key Insights

* Most reviews contain positive ratings.
* Genuine reviews focus on detailed student experiences.
* Deceptive reviews often contain promotional language and exaggerated claims.
* NLP features significantly improve review classification performance.
* Machine learning models can effectively identify suspicious review patterns.
